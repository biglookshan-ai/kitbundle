## 这次上线改什么

只改两个结算程序(Function),页面、后台、数据库、已有的套装 / 赠品设置都不动:

| 程序 | 改什么 |
| --- | --- |
| `extensions/addon-discount`(折扣) | 套装主产品 / 配件必须是套装提供的款式;免费配件组检查主产品款式;隐藏中的组不生效;限时折扣件数分款式;免费送的东西不算「已购买」 |
| `extensions/gift-guard`(结算拦截) | 免费送的东西(`_cgp_free`)不算「已购买」 |

上线前正式版本:**kitbundle-125**(2026-11-09 07:17 UTC,代码 = 提交 `03f9cfe`)。
这次的代码 = 提交 `f6e6c9e`(和 125 比只有上面两个程序 + 测试)。

## 无损复位(1 分钟,不丢任何数据)

KitBundle 的折扣和拦截程序**不存任何数据**,所有设置都在店铺的产品字段和折扣里,复位只是换回上一版程序:

```bash
cd "~/Vibe Coding Dev/Shopify App/kitbundle"
npx shopify app release --version kitbundle-125
```

- 这条命令把 kitbundle-125 重新设为正式版本,不需要重新打包,已有的折扣 / 结算规则自动用回旧程序
- 产品字段、折扣节点、赠品活动、顾客购物车都不受影响
- 代码也要回去的话:`git revert f6e6c9e`(不要硬重置,保留记录)

## 什么情况要复位

- 正常的套装 / 加购 / 赠品不再打折(下面的「上线后核对」A、F、G 任何一项失败)
- 结算页报错、或者正常买 LIVE AIR 4 + 赠品被拦
