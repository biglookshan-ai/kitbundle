⑤ 改了什么

地方文件改动
主题（普通产品）snippets/buy-buttons.liquid去掉购物车图标；按钮里加金额（款式价 × 数量）；附上各款式价格给脚本用
assets/cgp-atc.css（新）全大写、细体、字距；卖完不显示金额、不划黑；手机数量框 104px；放不下时金额换行
assets/cgp-atc.js（新）切换款式、改数量时实时更新金额
KitBundleassets/addon-save.js按钮文字 =「主题按钮文字 - 总额」，有配件 / 赠品时 =「ADD N ITEMS TO CART - 总额」；去掉总价框；数量和按钮包成一行；加载转圈；只读主题按钮的文字部分（不带金额）
assets/addon-save.css新按钮样式（同主题）、划黑动画、数量框同主题（47px、细线 − +）、卖完、加载、手机
blocks/addon_save.liquid数量和按钮包进同一行（脚本也会自己包，旧版 block 也能用）

件数怎么算：主产品或套装里的每一件 × 数量 + 加购配件 + 赠品。只有主产品时显示 ADD TO CART；预售时显示 PRE-ORDER NOW - 金额（有配件时 PRE-ORDER N ITEMS - 金额）。

⑧ 上线顺序和还原

  • 先上 KitBundle，再推主题。反过来的话，中间那段时间旧 KitBundle 会把主题按钮里的金额一起抄过去，显示成「ADD TO CART-£289.00」挤在一起（测试时看到过）。
  • 还原主题：把本文件夹（主题仓库同名文件夹）before/snippets/buy-buttons.liquid 推回正式主题即可；两个新文件不引用就不起作用。
  • 还原 KitBundle：npx shopify app release --version kitbundle-128（上线前的版本）。
